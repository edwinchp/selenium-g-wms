# 🧪 Selenium Framework

Selenium WebDriver framework using Page Object Model and powered by Cucumber Reports.

---

## 🚀 Getting Started

### 1. Prerequisites

- Java 11+ (Tested with Java 21)
- Maven 3.x
- Google Chrome installed

---

### 2. Clone the Project

```bash
git clone https://github.com/edwinchp/selenium-g-wms.git
cd selenium-g-wms
```

### 3. Set the Cucumber Publish Token (optional, for sharing reports)
You can generate your token at https://reports.cucumber.io/profile and set it like this:
```bash
export CUCUMBER_PUBLISH_TOKEN=your_token_here 
```


### 4. Run the Tests
```bash
mvn test
```
